# Бот для "Билета в будущее" 🎓

Скрипт автоматически открывает сайт bvbinfo.ru, вводит логин и пароль, нажимает на кнопку "Войти", переходит в раздел "Мои горизонты" и заполняет анкеты.

## 🚀 Как запустить скрипт

1. Установи библиотеку для управления браузером:
pip install playwright
playwright install chromium

2. Открой файл test.py и впиши свои реальные данные в самом верху:
LOGIN = "твой_логин"
PASSWORD = "твой_пароль"

3. Запусти скрипт через терминал:
python test.py
